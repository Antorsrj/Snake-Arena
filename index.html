Config

All the games, with the exception of the Opus5.5, were generated using OpenCode with free tier models or on local machines using llama.cpp on a RX 9070 XT and a RTX 5070 TI. All on Linux. Arch btw! The site was also made using OpenCode running on a local Qwen3.8 Next Flash.

Prompt


Create a complete, self-contained clone of the classic Snake game that runs entirely in a modern web browser.

Requirements:
- Single HTML file with embedded CSS and JavaScript (no external libraries or dependencies).
- Full Cyberpunk / Matrix aesthetic:
  - Dark background with digital rain / falling green code effect (Matrix-style).
  - Neon green, cyan, and magenta accents.
  - Glitch effects and subtle scanlines.
  - Futuristic fonts and UI elements that look like a terminal or cyber interface.
- Smooth gameplay with keyboard controls (Arrow keys + WASD).
- Score display, high score (saved in localStorage), and game over screen.
- Increasing difficulty as the snake grows.
- Responsive design that works well on desktop.
- Clean, well-commented code.

Make the game visually impressive and atmospheric while remaining fully playable. Output only the complete HTML file.
